# Sketch: Do Networks Represent Properties or Store Answers?

**Status:** parked. Revisit after the binomials paper is settled.
**Relation to the main paper:** independent. Uses none of the binomials pipeline,
only the conceptual framing.

---

## The question

A standard objection to probing: if a probe recovers some quantity from a model's
representations, that may only show the model has stored the *answer* on some
direction, not that it represents the structure that produces the answer. The
objection is correct in principle — the two are mathematically indistinguishable
from a probe alone.

But "possible" and "what actually happens" are different claims. Given a task whose
answer genuinely is determined by abstract properties, does a trained network end up
representing those properties separably, or does it collapse them into a scalar
answer axis?

That's an empirical question about inductive bias, and it's answerable by training
networks on data whose generative structure we control.

## Why it's worth a paper

It converts an unfalsifiable-in-principle objection into a measurement:

> We trained N models on data where the answer is known to be property-derived.
> In M of them the properties are separably encoded; in K the representation
> collapses to a scalar answer axis.

If M/N is high, the readout account stops being a live concern for interpreting
probe results and becomes a theoretical edge case. If it isn't, that's a genuine
warning to the probing literature. Either outcome is publishable.

Note this cannot be answered by simulating representations directly — that requires
hand-specifying the encoding, which assumes the answer. The networks have to be
trained.

## Design

**Synthetic language.** Vocabulary where each word carries known properties (length,
frequency, a phonology-like feature). Some target construction — binomial ordering is
the natural choice — is generated by a known rule over those properties, plus a
controlled set of memorized exceptions that violate it.

**Training.** Small transformers on next-token prediction, 2–4 layers, small vocab.
Cheap enough to train dozens per condition on one GPU.

**Discovery, with ground truth in hand.**
- Are the individual properties independently decodable from the representations?
- Does the answer direction lie inside the span of the property directions
  (property-derived) or largely orthogonal to it (arbitrary storage)?
- Does ablating a property direction shift predictions the way the rule says it should?

**Sweep.** Seeds, model size, corpus size, and most importantly the **proportion of
memorized exceptions** and **per-item frequency**.

## The finding to aim for

Not "networks usually encode properties," which is a single number, but the
**boundary**: the data conditions under which networks stop encoding properties and
start storing answers. Then ask where realistic LM training sits relative to that
boundary.

The prediction worth testing is that answer-storage grows with the exception rate and
with per-item frequency — which would connect directly to the U-shaped
frequency-residual result in the binomials paper, where probe error rises at the
high-frequency tail.

## Caveats to state up front

- Toy-model inductive bias does not transfer automatically to billion-parameter
  models on natural corpora. The claim is "here is what networks do under conditions
  we can control," not "therefore Pythia does this."
- The property set must be genuinely learnable but not trivially so, or the result is
  rigged by the design rather than discovered.

## Existing groundwork

- `Scripts/simulation_validate_measures.py` — synthesises representations with
  hand-specified encodings and checks what each measure reports. Answers a *different*
  question (measure selectivity, not inductive bias), but the measurement code and the
  antisymmetric ridge probe are reusable.
- Already established there: β₂ is highly selective for pair-specific memory
  (r = +0.95 with the true component, ~0 with the others), while word-held-out R²
  responds to both feature-derived abstraction and arbitrary per-word storage when the
  latter sits on a shared axis — which is exactly the ambiguity this paper would resolve.
